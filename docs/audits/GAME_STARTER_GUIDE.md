# 矮人要塞 上手指南(经典版 + HEWN 图形 + 中文汉化)

> 本指南同时安装在游戏目录 `~/Games/DwarfFortress/上手指南.md`, 两处同步更新。

## 每次启动

```
启动器点 "Dwarf Fortress" (或终端: cd ~/Games/DwarfFortress && ./dfhack)
```

## 图形 + 中文设置(经典版, 只需一次)

1. **开中文**: 游戏里随时按 **`Ctrl+F2`** 开关中文(默认已开, 主菜单应为中文)
2. **ASCII 渲染选项保持 Yes**: 设置(Settings) → `Use Classic ASCII Glyphs` → **保持 Yes**
   ⚠ 经典版**没有图形包时设为 No 会黑屏**(该选项是图形渲染主开关, 无贴图资源时设 No 渲染空白)
3. 画面已换 **16×16 方块大字**字体(游戏自带, 比原字符大 60%), 想改回小字体:
   编辑 `prefs/init.txt` 把 `curses_square_16x16.png` 改回 `curses_640x300.png`

## 为什么不用图形包(HEWN 教训, 2026-09-08)

曾尝试给经典版安装 HEWN 图形包(v53 现役方案, DFFD id=17744), 三次组合全失败:

- 带 raws 启用 → 闪退(SIGSEGV, 53.10 raws 与 53.16 不兼容)
- 只保留 HEWN → 黑屏(无任何原版数据)
- 纯贴图层(移除 raws) → 仍闪退(overlay 插件空指针)

结论: **经典版 + 53.16 没有可用的现成图形包**; 改用字体美化(零风险)。
旧一批的 Phoebus/DFgraphics 最高支持 47.05, 不支持 v50+。
想要真图形+高质量中文的终局方案仍是: steam 版 + 工坊 DFI18n。

## 从零开始的最短路径

### ① 生成世界
参数默认(世界尺寸选**最小**, 历史选**短**最省时间) → 生成完挑一个地点进入。

### ② 选落脚点(要塞选址)
- 绿色区域(森林)优先: 有树有水
- 避开红色/紫色区域(邪恶生物/亡灵), 新手必死
- 找**河流或湖泊旁的平缓山坡**(坡度符号浅=好挖)
- 确认 `出发/Embark`

### ③ 出发队形
- 新手直接用默认 7 矮人, 不用精挑
- 物资建议: **酒多带**(矮人不喝酒干活变慢还会抑郁)、食物各一份、一把斧、一把镐; 铁砧可不带(省钱)
- 点 `出发` 进入游戏

### ④ 落地后第一个月(按顺序做)

| 步骤 | 干什么 | 中文菜单位置 |
|---|---|---|
| 1 | 按 **空格暂停**, 先别慌 | — |
| 2 | 划一块**地下储藏区**(5×5 够用) | 底部菜单 `挖掘` → 划矩形 |
| 3 | 划 **树木砍伐区**(就近 10×10) | `采伐` |
| 4 | 挖完 → 放**木材储存堆**和**食物储存堆** | `放置储存区` |
| 5 | 挖几间小屋当**卧室**, 放床 | `建造` → 家具 → 床(需先有木料) |
| 6 | 建 **木工坊、石匠坊** | `建造` → 工坊 |
| 7 | 地下划一块 **农田**, 种酒用作物 | `耕作` |
| 8 | 建 **蒸馏坊** 酿酒(生存核心!) | `建造` → 工坊 → 蒸馏 |

### ⑤ 之后的心智模型
- 矮人**全自动**, 你只负责"下指令+划区域", 活儿他们自己干
- 右上角**公告**滚动播报(DF-FanYi 引擎会翻译成中文字幕)
- 出问题先看公告: 缺木头/缺床/有人饿晕, 按提示补就行
- **矮人会死, 要塞会亡, 这是正常的**——每次失败都是新故事

## 常用键位

| 键 | 作用 |
|---|---|
| `空格` | 暂停/继续(遇事不决先暂停) |
| `Ctrl+F2` | 中英文切换 |
| 鼠标 | v50+ 支持鼠标点选大部分菜单和地图 |
| `Esc` | 返回上级菜单 |

## 翻译覆盖说明

- 中文来自 dfint 汉化: 菜单/界面/物品/生物名已覆盖(见 UI_I18N_GUIDE.md)
- 没翻译到的文本保持英文, 不影响操作
- 描述类长文本由 DF-FanYi 引擎云端预翻译逐步补全

## 出问题

- 画面崩/花屏 → 删 `data/mods/HEWN`, 还原 `data/init/colors.txt`(备份 `.backup-before-hewn-*/`)
- 想回纯字符画 → 设置里 `Use Classic ASCII Glyphs` 设回 Yes
- 汉化失效 → 看 `dfint-data/dfint-log.log`
- 更多教学 → B 站搜"矮人要塞 新手"
