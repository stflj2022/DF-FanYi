# 矮人要塞 上手指南(经典版 + HEWN 图形 + 中文汉化)

> 本指南同时安装在游戏目录 `~/Games/DwarfFortress/上手指南.md`, 两处同步更新。

## 每次启动

```
启动器点 "Dwarf Fortress" (或终端: cd ~/Games/DwarfFortress && ./dfhack)
```

## 图形 + 中文设置(经典版, 只需一次)

1. **激活图形包**: 主菜单 → **创建新世界** → 世界创建流程里会出现**模组勾选**步骤 → 勾选 `HEWN`
   > 经典免费版**没有主菜单 Mods 入口**(付费版才有); 模组在创建新世界时激活,
   > 已存在的世界无法追加。也可在标题屏用 DFHack `gui/mod-manager`。
2. **关掉字符画**: 设置(Settings) → `Use Classic ASCII Glyphs` → **No**
   (找不到就先进世界看效果, 图形包生效后大半画面已是贴图)
3. **开中文**: 游戏里随时按 **`Ctrl+F2`** 开关中文(默认已开)

## 从零开始的最短路径

### ① 生成世界
参数默认(世界尺寸选**最小**, 历史选**短**最省时间) → 生成完挑一个地点进入。

### ② 选落脚点(要塞选址)
- 绿色区域(森林)优先: 有树有水
- 避开红色/紫色区域(邪恶生物/亡灵), 新手必死
- 找**河流或湖泊旁的平缓山坡**(坡度符号浅=好挖)
- 确认 `出发/Embark`

### ③ 出发队形
- 新手直接用默认 7 矮人, 不用精挑
- 物资建议: **酒多带**(矮人不喝酒干活变慢还会抑郁)、食物各一份、一把斧、一把镐; 铁砧可不带(省钱)
- 点 `出发` 进入游戏

### ④ 落地后第一个月(按顺序做)

| 步骤 | 干什么 | 中文菜单位置 |
|---|---|---|
| 1 | 按 **空格暂停**, 先别慌 | — |
| 2 | 划一块**地下储藏区**(5×5 够用) | 底部菜单 `挖掘` → 划矩形 |
| 3 | 划 **树木砍伐区**(就近 10×10) | `采伐` |
| 4 | 挖完 → 放**木材储存堆**和**食物储存堆** | `放置储存区` |
| 5 | 挖几间小屋当**卧室**, 放床 | `建造` → 家具 → 床(需先有木料) |
| 6 | 建 **木工坊、石匠坊** | `建造` → 工坊 |
| 7 | 地下划一块 **农田**, 种酒用作物 | `耕作` |
| 8 | 建 **蒸馏坊** 酿酒(生存核心!) | `建造` → 工坊 → 蒸馏 |

### ⑤ 之后的心智模型
- 矮人**全自动**, 你只负责"下指令+划区域", 活儿他们自己干
- 右上角**公告**滚动播报(DF-FanYi 引擎会翻译成中文字幕)
- 出问题先看公告: 缺木头/缺床/有人饿晕, 按提示补就行
- **矮人会死, 要塞会亡, 这是正常的**——每次失败都是新故事

## 常用键位

| 键 | 作用 |
|---|---|
| `空格` | 暂停/继续(遇事不决先暂停) |
| `Ctrl+F2` | 中英文切换 |
| 鼠标 | v50+ 支持鼠标点选大部分菜单和地图 |
| `Esc` | 返回上级菜单 |

## 翻译覆盖说明

- 中文来自 dfint 汉化: 菜单/界面/物品/生物名已覆盖(见 UI_I18N_GUIDE.md)
- 没翻译到的文本保持英文, 不影响操作
- 描述类长文本由 DF-FanYi 引擎云端预翻译逐步补全

## 出问题

- 画面崩/花屏 → 删 `data/mods/HEWN`, 还原 `data/init/colors.txt`(备份 `.backup-before-hewn-*/`)
- 想回纯字符画 → 设置里 `Use Classic ASCII Glyphs` 设回 Yes
- 汉化失效 → 看 `dfint-data/dfint-log.log`
- 更多教学 → B 站搜"矮人要塞 新手"
