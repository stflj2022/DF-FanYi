> Dwarf Fortress **Steam 版 v53.06**（64 位）整合包
> 本包 = 游戏本体 + 免 Steam 运行 + 中文界面(dfint 汉化) + DFHack 53.06-r1 + DF-FanYi AI 动态汉化引擎桥
> 效果：界面、生物/物品名称与描述为中文；**公告、事件、战报等动态文本实时翻译成中文**显示在屏幕底部；

>
> ⚡ **迁到新 omarchy 电脑只需三步**（拷目录 → 跑一条命令 → 填个 key），详见[第十一节](#十一整包迁移到新-omarchy-电脑三条命令)。

## 三、解压 / 拷贝到新机器

### 方式 A：从压缩包解压（首次拿到分卷包）

收到的是分卷压缩文件（`.7z.001 / .7z.002 / ...`），需全部下载在同一文件夹：

- **Windows**：安装 [7-Zip](https://www.7-zip.org) → 右键第一个 `.7z.001` → 选择“解压到当前文件夹”（会提示输入密码）
- **Linux**：`7z x 文件名.7z.001`（按提示输密码）

### 方式 B：从另一台 omarchy/Linux 机整目录迁移（推荐）

在旧机器上拷出（排除运行垃圾，更快更干净）：
```bash
rsync -a --progress \
  --exclude 'crashlogs/' --exclude 'fanyi-debug.log' --exclude 'errorlog.txt' \
  --exclude 'gamelog.txt' --exclude 'stderr.log' --exclude 'stdout.log' \
  --exclude 'install-df-fanyi.log' --exclude 'DF-FanYi/' \
  ~/Games/DF-v5306/Dwarf\ Fortress/  新机:~/Games/
# 存档在 data/save + userdata 随目录一起走，不受排除项影响
```
> `DF-FanYi/`（旧机器上的引擎克隆）排除掉 —— 新机器跑安装脚本会重新克隆，避免旧路径残留；
> 离线翻译包快照(`DF-FanYi-离线翻译包/engine.db`)已随包带走，学习成果不丢。

解压/拷贝后得到 `Dwarf Fortress` 文件夹。

> ⚠️ **必须解压到纯英文/数字路径**（如 `D:\Games\DF` 或 `~/Games/DF`）。
> 路径含中文/空格会导致游戏贴图加载失败，弹窗报 “Tileset not found”（实际是路径问题，别被报错误导）。

## 四、启动游戏

### Windows
双击 `Dwarf Fortress.exe` 即可 → DFHack 与汉化自动加载，进主菜单就是中文。

### Linux（Steam + Proton，推荐）
1. 安装 Steam，登录后开启 Proton：设置 → 兼容性 → 勾选“为所有其他产品启用 Steam Play”，兼容层选 Proton Experimental
2. Steam → 左下角 **添加游戏 → 添加非 Steam 游戏** → 浏览，选中 `Dwarf Fortress.exe`
3. 库中找到它 → 右键 → 属性 → 兼容性 → **强制使用特定的 Steam Play 兼容性工具**：选 **GE-Proton11-6**（未安装则先在兼容层文件夹或 ProtonUp-Qt 装好）或 Proton Experimental
4. 启动游戏

> 装完 DFHack 后首次启动会比平时慢（初始化前缀），耐心等 1–2 分钟。

## 六、克隆翻译引擎（α 实时翻译的基础）

> 💡 **新机器推荐直接用一键脚本（第十一节），下面的手动方式二选一即可，两者等价。**

公告、事件、战报等动态文本不在静态词典里，需要 **DF-FanYi 引擎**实时翻译。

```bash
# 1. 克隆引擎（需要 Python ≥ 3.11，Arch 系自带；Ubuntu 需先装 python3.11+）
git clone https://github.com/stflj2022/DF-FanYi.git
cd DF-FanYi

# 2. 创建 Python 虚拟环境并安装
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

# 3. 放置离线翻译包（本整合包附带，5 秒完成）
mkdir -p data
cp <你解压出的路径>/DF-FanYi-离线翻译包/engine.db data/

# 4. 启动引擎桥（保持此终端窗口开着；建议开机自启，见常见问题 6）
python -m df_fanyi bridge --transport tcp --port 17486
```

看到 `桥已启动: tcp 127.0.0.1:17486` 即成功。

## 七、配置 AI 模型（可选，强烈建议）

离线词典覆盖常见句子；未覆盖的动态文本由 AI 模型翻译。**二选一**：

### 方案 A：本地模型（免费、离线、隐私好；CPU 可跑但较慢）
```bash
# 安装 ollama：https://ollama.com（或 Linux: curl -fsSL https://ollama.com/install.sh | sh）
ollama pull gemma-4b-trans   # 约 5.3GB；CPU 也能跑（慢一些，但完全免费）
```
本项目 `config/default.yaml` 的 `local_llm.base_url` 默认就是 `http://127.0.0.1:11434`，无需改。

### 方案 B：云端模型（快，需 API Token）
- 启动 Pi Model Router（`model-router`，监听 127.0.0.1:8010），或
- 改 `config/default.yaml` 的 `providers` 加入任意 OpenAI 兼容端点；密钥放 `~/.config/df-fanyi/secrets.env`（**密钥绝不进 Git**）

### 不配 AI 会怎样？
引擎照常工作：能命中的（预翻 + 词典）出中文，未命中的安静显示原文。游戏永不卡顿、永不出错——但全中文覆盖率取决于你的模型配置。所以想完整中文体验就配一个。

## 常见问题（FAQ）

**1. 启动弹 “Tileset not found” / 画面花屏**
路径含中文/特殊字符 → 整个文件夹移到纯 ASCII 路径（见第三节）。

**2. 公告还是英文**
按顺序排查：
1) 引擎桥是否已启动（`python -m df_fanyi bridge ...`）？没起就起一个，再重进游戏（fanyi 会自动重连）。
2) 查看桥日志 `logs/engine.log`：若有 `LLM 调用失败, 回退原文` → 说明没配 AI 模型且该句不在离线词库，按第七节配一个模型。
3) 确认离线翻译包已复制（第六节第 3 步）。

**3. 字幕条没显示**
游戏内 DFHack 控制台执行：`fanyi overlays on cjk`

**4. 杀毒软件/防火墙报毒**
`steam_api64.dll`（Goldberg 免 Steam 模拟器）是常见误报源，无病毒。加入白名单即可。

**5. 存档在哪 / 换机迁移**
存档在游戏目录内 `data/save/` + `userdata/`，随文件夹整体走；但引擎/服务/快捷键
需要在新机器跑一次 `install-df-fanyi-omarchy.sh`（三条命令完整流程见第十一节）。

**6. Linux 开机自启引擎桥（systemd）**
```ini
# ~/.config/systemd/user/df-fanyi-bridge.service
[Unit]
Description=DF-FanYi translation bridge
After=network.target
[Service]
Type=simple
WorkingDirectory=<你的DF-FanYi克隆路径>
ExecStart=<你的python路径> -m df_fanyi bridge --transport tcp --port 17486
Restart=always
RestartSec=5
[Install]
WantedBy=default.target
```
```bash
systemctl --user daemon-reload
systemctl --user enable --now df-fanyi-bridge
```

**7. 需要 Steam 账号才能玩吗？**
不需要。本包内置免 Steam 运行（Goldberg 模拟器），联网与账号都非必需；Steam 只是 Linux 下跑 Proton 的载体。

## 十一、整包迁移到新 omarchy 电脑（三条命令）

目标：把 `Dwarf Fortress` 文件夹拷到另一台 omarchy 机器，**完整复刻本机效果**——
中文界面 + 公告实时字幕 + Ctrl+Print 截图框选即译 + 离线词库 + 云端 AI 路由。

游戏目录已自带全部迁移资产（`omarchy-tools/`、`model-router/`、最新 engine.db 快照），
一键脚本会把它们装到新机器的对应位置（全部幂等，重跑安全）：

| 资产 | 装到哪 | 作用 |
|---|---|---|
| 引擎克隆 DF-FanYi | `游戏目录/DF-FanYi/` | 翻译引擎源码+venv |
| engine.db 快照 | `DF-FanYi/data/` | 8034 句预翻译（仅首次，不覆盖新机学习成果） |
| fanyi.lua | `hack/scripts/` | 与引擎 repo 同步的运行副本 |
| 调优 config.yaml | `~/.config/df-fanyi/` | 队列调优（战斗瞬时不过载；旧配置自动备份） |
| chi_sim OCR 包 | `~/.local/share/tesseract/tessdata/` | 截图识中英文 |
| fanyi-shot 脚本 | `~/.local/bin/` | 引擎路径自动注入，无需改脚本 |
| hypr 快捷键+浮窗规则 | `~/.config/hypr/{bindings,windows}.lua` | Ctrl+Print 绑定 + 浮窗悬浮置顶（幂等追加，自动 reload） |
| model-router | systemd 服务 `df-fanyi-router` | 云端 AI 路由（额度软降级自动切供应商） |
| 引擎桥 | systemd 服务 `df-fanyi-bridge` | 常驻 127.0.0.1:17486，开机自启 |

### 三步操作

```bash
# ① 新机器：把整个文件夹拷过去（旧机器上执行，排除运行垃圾；见第三节方式 B）
# ② 新机器：跑一键脚本
cd ~/Games/Dwarf\ Fortress
bash install-df-fanyi-omarchy.sh
# ③ 填 API key（云端 AI 用；不填则纯离线，词库外句子显示原文）
cp model-router/env.example model-router/env
nano model-router/env          # 填 MINIMAX_API_KEY / GLM_API_KEY
systemctl --user restart df-fanyi-router
```

### 验证
```bash
systemctl --user is-active df-fanyi-bridge   # → active 引擎桥在跑
systemctl --user is-active df-fanyi-router   # → active AI 路由在跑(填了 key 才有)
```
1. 进游戏触发一条公告 → 底部中文字幕 ✓
2. 任意界面按 **Ctrl+Print** 框选一段文字 → 浮窗弹出连贯中文 + 已进剪贴板 ✓
3. DFHack 控制台 `fanyi status` → 引擎在线 ✓

> 💡 缺工具提示：脚本会检查 slurp/grim/zenity/wl-copy/tesseract，缺啥按提示
> `pacman -S` 装上重跑即可（omarchy 一般只缺 tesseract）。
> 🔒 安全：脚本只写用户目录（systemd user 服务、~/.local、~/.config），不 sudo；
> API key 只存本地 `model-router/env`，绝不进包/git。
